# ViewMagnet — robots.txt
# https://viewmagnet.io

# Policy summary:
#   - All marketing + reference pages: open to every crawler.
#   - Dashboard, auth, account routes: blocked (private).
#   - AI / generative-engine crawlers: explicitly allowed on
#     public content so we are eligible for ChatGPT, Perplexity,
#     Claude, Bing Copilot, and Google AI Overviews citations.
#   - Aggressive scrapers / known-bad bots: blocked further down.
#
# If you change this file, also update:
#   - frontend/client/public/sitemap.xml (lastmod entries)
#   - frontend/client/public/llms.txt    (AI crawler index)

# accuracy" or "how does YouTube's algorithm decide reach" are
